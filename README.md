## 3. A Recent Cybersecurity Incident
**McKesson data breach (August 2026):** The healthcare and pharmaceutical distributor McKesson told the SEC it found unauthorized access to third-party applications on August 25. The hacking group ShinyHunters claimed it stole patient data.

**What I learned:** Attackers often get in through third-party applications rather than the main company systems, so a company is only as secure as the vendors it connects to. It also shows why healthcare data is such a valuable target.
